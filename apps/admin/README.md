# StackTrack admin

The admin package is a responsive React/Vite operations console. It links the reusable-container overview, asset register, validated load-code list, locations, accuracy review queue, append-only activity, devices, reports, and prototype settings.

It also retains the independent correction-policy module: routine classification cleanup defaults to a store manager, while location changes, conflict resolution, processed percentage, and already-reported periods require a separate corporate data steward. Goodwill must approve this policy before the pilot.

Run it from the repository root with `npm.cmd run dev:admin`.
